Open-Source vs Proprietary API Keys Explained
1. Groq Cloud (Recommended Free Open-Source)

Provides completely free API keys with high rate limits (30 req/min). Runs top open-weights models like Meta Llama 3.3 70B and DeepSeek R1 Distill on specialized LPUs at blistering speeds (500 tokens/sec).

2. Ollama / Local (Zero Keys, 100% Offline)

Run models completely on your own machine (Mac/Windows/Linux). No external server, no monthly bills, 100% private for confidential thesis data. Simply download from ollama.com and run ollama run llama3.2.

3. OpenRouter Free Tier

One unified API key for hundreds of models. Models suffixed with :free (e.g. deepseek/deepseek-r1:free or meta-llama/llama-3.3-70b-instruct:free) cost $0 to run.

4. Built-in Academic Agent (Zero Config)

If you don't want to get any API key at all, the dashboard's built-in NLP agent connects to OpenAlex & CrossRef for paper discovery and generates structured thesis synthesis without external tokens.
